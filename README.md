# PS5060 Class 11 data

`NYC_weather.csv`: daily weather observations at NY City Central Park (GHCN-Daily station USW00094728),
1996-01-01 to 2025-12-31, from NOAA NCEI. Used in the Class 11 neural network exercise.

Load it in Python or Colab with:

```python
import pandas as pd
df = pd.read_csv('https://raw.githubusercontent.com/youtingw11/ps5060-class11-data/main/NYC_weather.csv')
```

Variable descriptions: see NOAA's GHCN-Daily documentation.
